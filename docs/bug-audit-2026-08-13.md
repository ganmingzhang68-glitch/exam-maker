# 项目缺陷审查与修复记录

日期：2026-08-13

## 审查范围

- Phase 6–12 新增的练习、教学分析、成绩复核、管理员和组织边界。
- 考试发布、学生作答、题目质量、批改和成绩展示核心链路。

- 现有自动化测试、TypeScript、ESLint、前端生产构建和真实浏览器页面。

## 已确认并修复

| 等级 | 缺陷 | 修复 |
|---|---|---|
| 高 | 未显式发送组织头时，教师列表接口没有应用默认组织范围。 | 课程、班级、题目、试卷、考试及 Dashboard 对非管理员始终应用组织上下文；管理员只有在显式选择组织时受该范围限制。 |
| 高 | 无组织成员关系的非管理员会静默落入组织 1。 | 中间件现在返回 403；没有默认组织时使用该用户首个真实成员关系，不再猜测。 |
| 高 | 发布考试会给所有组织的学生创建 assignment。 | 仅给考试所属组织中启用的学生分配。 |
| 高 | 班级搜索、导入和添加可以选择其他组织学生。 | 所有候选学生必须是班级所属组织的有效成员。 |
| 高 | 考试质量、成绩、作答、学习分析、教学分析、练习和复核部分深链接缺少组织上下文检查。 | 在资源入口和列表服务补充 organization_id 校验及过滤。 |
| 高 | 同一教师可把其他组织的题目加入试卷，或把其他组织试卷替换到考试。 | 强制 Question、Paper、Course、Exam 的组织一致性。 |
| 中 | 已判分练习题在整组完成前可以用 API 再次提交并覆盖分数。 | 已判分题返回 409；回归测试验证分数不可覆盖。 |
| 中 | 教学分析把总分为 0/损坏的历史试卷作答按 0 分纳入平均值。 | 只平均分母有效的得分率；无有效样本返回 null。 |
| 中 | 教学分析快照或质量标记 JSON 损坏会让整个 Dashboard 报错。 | 损坏快照标记 failed 并确定性重建；损坏标记按空数组降级。 |
| 中 | JWT 查询参数对所有 API 生效。 | 只允许项目 SSE 和文件下载路径使用查询 token；其他接口必须使用 Authorization header。 |
| 中 | 查询 token 会原样出现在 HTTP 访问日志。 | 日志格式对 `token` 参数统一替换为 `[REDACTED]`。 |
| 中 | 学生成绩及教师批改页面把空标准答案显示为字符串 `null`。 | 统一显示“未设置”；已用真实浏览器验证。 |
| 低 | 成绩列表和学生考试列表存在逐学生/逐考试重复查询。 | 一次批量读取 attempts 后按 student/exam 分组。 |

## 尚未处理

1. Ant Design 静态 `message` / `Modal` 在动态主题下仍产生控制台警告，需要全站迁移到 `App.useApp()`。
2. 前端主包仍约 1.45 MB，需要按路由懒加载；不影响本次正确性修复。

4. 历史考试 ID 1 的题干/答案数据本身仍有脏数据；本次仅修复安全展示，没有擅自改写历史题目。
