# Phase 11 性能实测报告

执行命令：`npm run load-test:phase11 -w server`

执行环境：2026-08-13，本地 Node.js 24.14.0、SQL.js 内存数据库、单个 Express 进程。测试同时保留一条状态为 `running` 的 AI 后台任务；不发起外部模型网络调用。

| 场景 | 请求数 | p50 | p95 | max |
|---|---:|---:|---:|---:|
| 100 学生同时进入考试 | 100 | 384.6 ms | 507.9 ms | 524.4 ms |
| 100 学生同时保存答案 | 100 | 248.4 ms | 252.7 ms | 262.3 ms |
| 100 学生各重复提交两次 | 200 | 473.8 ms | 581.2 ms | 581.8 ms |
| 教师打开 100 人成绩册 | 1 | 24.5 ms | 24.5 ms | 24.5 ms |

重复提交阶段总墙钟时间 601.5 ms。完整性检查：100 条 attempt、100 条 answer、100 条 graded；重复计分 0、数据丢失 0、HTTP 错误 0。

这些数字是本机内存数据库基线，不代表生产 SLA。测试已经覆盖结束前集中 autosave/submit 所关心的幂等性和数据完整性，但没有模拟真实磁盘延迟、反向代理、多实例、外部 AI 延迟或跨地域网络。生产发布前需要在目标硬件与实际数据库上复跑。
