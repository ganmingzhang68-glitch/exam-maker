# Product V1 浏览器巡检

审计日期：2026-08-13  
地址：`http://localhost:5173`  
方式：连接已启动的 Edge CDP 会话，分别使用 `test_teacher` 与 `test_student` 实际登录。

## 教师端

### 教师 Dashboard

- `/` 登录后展示教师工作台，而不是技术项目列表。
- 实测显示进行中课程、班级、已发布考试、待批改和近 7 日提交。
- 近期考试显示课程、发布范围兼容提示、时间、提交数、待批改数和状态。
- AI 项目失败会出现在“需要处理”区域。
- 浏览器未观察到 Ant Design error message。

### 课程与班级

- `/courses` 可加载迁移后的“高等数学（上）”，显示试卷/考试真实统计。
- `/courses/1` 可打开课程详情，显示概览和各业务入口。
- `/classes?courseId=1` 可按课程打开班级列表，空态和创建入口正常。
- 班级创建/成员变更的后端行为由 API 测试覆盖；本轮没有在持久化演示库中写入虚构成员。

### 题库

- `/questions` 实测加载真实 AI 题目。
- 页面显示课程、题型、来源、使用状态、难度、来源文件和排序等筛选器，以及批量选择入口。
- `/questions/33` 实测显示题干、答案、解析、Rubric、属性、试卷引用、修改历史；无足够样本时不显示虚假统计。
- 浏览器未观察到页面错误。

### 试卷库

- `/papers` 实测显示“微积分”试卷。
- 实际字段包括 4 道题、100 分、估算难度、人工组卷、使用 1 次，并正确显示“已使用”。
- 搜索、课程/状态筛选、复制和编辑入口可见。
- 浏览器未观察到页面错误。

## 学生端

### 学生 Dashboard 与过期恢复

- 学生登录后由 `/` 自动进入 `/student/dashboard`。
- 实测显示待完成、进行中、即将开始、已完成、所属课程和最近成绩。
- 基线问题中的过期 `in_progress` attempt 已由后端自动结算为 `grading`。
- `/student/exams` 从基线的“当前 0、历史 0”修复为“当前 0、已结束与已完成 1”；切换历史页后真实显示“小测验 / 待批改 / 查看成绩”。
- 前端与 `GET /api/exams/mine` 对同一考试的状态一致。

## 已知限制

- Playwright 标准 MCP 仍因本机 Edge WebSocket 的 IPv4 `localhost:9222` 返回 404 无法直连；巡检使用同一 Edge 的 IPv6 CDP 地址完成。
- 本轮未完成按班级发布考试，所以历史考试仍标注“全部学生（兼容发布）”。
- 未完成题目导航、断网离线队列、Gradebook、通知、审计和统计分析页面；不能视为已验证。
