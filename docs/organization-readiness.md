# 多组织部署准备（Phase 10）

本阶段采用轻量组织模型，不引入复杂 SaaS：`organizations` 保存学校/学院，`user_organizations` 保存成员角色与默认组织。课程、班级、题目、试卷和考试均增加 `organization_id`。

迁移 024 创建“默认学校”，将全部旧用户加入并将全部旧核心资源回填到该组织，不删除或复制旧数据。新注册用户进入默认组织；管理员创建用户时进入当前组织。

客户端请求可通过 `x-organization-id` 选择组织，页面顶栏提供组织切换。普通用户必须是目标组织成员；管理员可全局查看，在显式选择组织后也受该组织范围约束。核心详情 API 同时执行原有所有权检查和组织检查，防止仅凭资源 ID 跨组织访问。

管理员 `/admin` 可创建组织并添加/更新成员。当前没有组织级计费、域名绑定、SSO 或复杂层级，这些不属于本阶段。
