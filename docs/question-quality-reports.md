# Question Quality Reports

`QuestionQualityReport` 由确定性考试统计产生并按 `exam_id + paper_question_id` 幂等更新。报告保存样本数、正确率、经验难度、区分度、点二列相关、选项分布、空答率、平均得分率和质量标记；重新打开考试分析会重算数值，但不会覆盖教师的处理状态。

选择题选项分析展示全体、高分组和低分组选择率。干扰项规则集中在 `assessment.ts`：

- `unused`：没有有效样本选择；
- `weak`：选择率低于配置阈值；
- `suspicious`：高分组选择错误项的比例显著高于低分组；
- `effective`：未触发上述规则。

这些状态是筛查提示，不是对题目质量的最终裁决。样本不足时不会产生确定性干扰项结论。

教师可对报告执行确认、忽略或加入待修订。加入待修订会把当前题库题目标记为 `needs_review`，不会修改考试快照，也不会删除 QuestionVersion。题库可按“需要复核”筛选。
